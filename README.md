# Number Guessing Game

A console game written in Java. The computer picks a random number
from 1 to 100, and you guess until you find it.

## Features
- Hints: "too high" or "too low" after each guess
- Counts how many guesses you took

## How to run
1. Install JDK 21
2. Open the project in IntelliJ IDEA
3. Run `Main.java`

## What I learned
- Using Random and Scanner
- While loops and if/else
